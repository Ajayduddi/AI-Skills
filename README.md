# AI Skills Repository Notes

## Purpose
This repository contains reusable AI skill definitions and instruction packs for workflow automation and knowledge management.

### n8n
- Turns any AI assistant into a production-grade n8n workflow engineer. Covers full CRUD — create, read, update, delete, activate, and execute workflows via `n8n-mcp` and `n8n-workflow-builder` MCP servers.

### Notion knowledge architect
- Enables AI assistants to manage Notion databases and pages effectively. Supports creating, reading, updating, and deleting Notion content through the `notion-mcp` server.

### subagent
- Run autonomous, tool-heavy tasks in a sub-agent and keep the main chat context clean. Ideal for complex operations that require multiple steps or interactions with external APIs, allowing the main assistant to focus on high-level guidance while the sub-agent handles the execution details.
